----------------------------------------------------------------------------
0. ROOT CAUSE (from TEST_RESULTS5/TEST_RESULTS6, confirmed)
----------------------------------------------------------------------------
- The OP effect is the exotic hullmod listener attach in HullmodExotic.refreshStatsEffects
  AcrossShipGraphs. Both the ROOT branch and the descendant loop were gated on the permaMod
  surviving on that exact variant instance (variant.hasHullMod).
- On the REFIT screen, getWholeVariantGraph() emits THREE trees: campaign, refit (checkRefit
  Variant), and display (getRefitDisplayVariant). The CheckAndInstall flows bookkeep + pour
  permaMod only on campaign instances whose getCorrectMods() resolves; the refit/display CLONES
  get only the $$EXOTICA$$ tag via writeThrough (ANCHOR-TARGET), never the permaMod, so
  refresh's hasHullMod gate skips their statsForOpCosts -> live OP on the refit bar and on the
  re-laid campaign tree never updates. Root kept working (ROOT branch + root re-install).
- On planetside "exoticatech" screen the refit/display trees identity-skip (=== campaign), so
  display clones do not exist there -> the pour is a no-op by construction.

----------------------------------------------------------------------------
1. STRATEGY (user-approved)  -- minimal, symmetric, DIAG-backed
----------------------------------------------------------------------------
- Pour addPermaMod onto the refit+display CLONE trees ONLY when runningFromRefitScreen(), so the
  installed-variant set is LARGER from refit than from the planetside screen.
- Symmetric strip of those clones on remove (refit-only gate), and harden the remove-side scrub
  so it is unconditional (permaMod may already be stripped by the remove flows before the scrub
  runs; removeEffectsBeforeShipCreation is idempotent / no-op where no listener exists).
- Attach side stays gated on hasHullMod so a module skipped at the exotic limit never gains a
  cost it did not buy.
- All new code is comment-free (user directive overrides RULES comment preservation for new
  blocks); existing comments untouched. All diagnostics are logger.error-class (AnonymousLogger).

----------------------------------------------------------------------------
- ROOT branch gate:   if (apply.not() || rootMember.variant.hasHullMod(hullmodId))
